# Programming Sequence Improvement Program (PSIP)

Every semester, hundreds of STEM students at Arkansas Tech University take the programming sequence courses — and too many of them don't make it through. The department's DFWI rates (students earning a D, F, withdrawing, or taking an incomplete) were running at 32%, 35%, and 27% across the three core programming courses. The Programming Sequence Improvement Program (PSIP) was created to change that.

## The goal

Increase first- and second-year student retention in the programming sequence:

- **COMS 2104** — Foundations of Computer Programming I
- **COMS 2203** — Foundations of Computer Programming II
- **COMS 2213** — Data Structures

by reducing DFWI rates **10% each year** from the 2015–2019 baselines of 32%, 35%, and 27% respectively.

## How it works

Four interventions, all aimed at the point where students struggle most:

1. **Tutoring lab** — a dedicated help lab for students enrolled in programming courses.
2. **Communication & collaboration tools** — Discord and Webex spaces so students can get help and work together outside class.
3. **Pedagogy research** — studying current best practices for teaching programming and bringing them into the classroom.
4. **Curriculum alignment** — connecting coursework with platforms students will actually use in the industry: GitHub, HackerRank, and LeetCode.
